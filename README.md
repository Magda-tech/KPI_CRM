## Análise de Dados — KPI's de CRM

Este repositório contém um notebook em Python que realiza a análise de um conjunto de dados em formato Excel (.xlsx). A análise inclui etapas de leitura, modelagem e visualização dos dados,
com o objetivo de analisar a evolução mensal de três indicadores-chave (KPIs) relacionados ao funil comercial de negócios:

Criação de negócios – quantidade de negócios criados por mês.

Passagem de negócios – negócios repassados ​​por DSE (pré-vendedores).

Ganhos – negócios fechados com sucesso (status "ganho").

Esses indicadores são cruzados com informações de divisão por loja (shopping), permitindo por localidade e ao longo do tempo ( AnoMes).
